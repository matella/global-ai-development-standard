# Agent adapters

Keep agent-specific configuration thin. The normative policy remains in `AGENTS.md` and `standard/`. Avoid duplicating rules across adapter files; link to the canonical policy instead.

Installed repositories place `standard/`, `agents/`, and `templates/` under `gads/`. See [PORTABILITY.md](PORTABILITY.md) for how roles reach each agent and [claude-code/README.md](claude-code/README.md) for the Claude Code adapter.
